  ## Static vs. Dynamic: The Difference That Changes Everything

  ## Static Web Pages(what you've built so far)
  ## Dynamic Applications. Involves server requests, a user database and a personalized response


  ## Why backend Development Exists
  ## When you move from static to dynamic, you encounter entirely new problems that frontend technologies can't solve: 
  ##    User Management - Who's visiting your site
  ##    Security - Users can view and modify any frontend code
  ##    Shared Data - Muutiple users need to see and modify 
  ##    Business Logic - Complex rules that shouldn't be available to users

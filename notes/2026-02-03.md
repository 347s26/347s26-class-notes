* Ensures that the structure of a database table is organized in a way that makes it easier to manage and query

## Second Normal Form (2NF) 
* Based on the concept of fully functional dependency. It is a way to organize a database table so that it reduces redundancy
* Not too much similarity between different rows - things on publisher should just be on
publisher, things on book should just be on book, little overlap is better, etc.
* No attributes depended on one another. - *is there some necessary change that will always happen* &rarr; for example, you shouldn't have "state" and "state abbreviation" as separate fields as it's redundant.

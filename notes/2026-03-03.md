## git multi-url-remote

- Remotes
1. origin
2. all (we will use to push to two different repos later) (optional)

`code .git/config`

- .git config file shows you are in the root of the git project.
- add the [remote "all"] section to add push urls to the project.
- Your existing repository is already there, add another url to your forked repo.

```
[remote "all"]
	pushurl = YOUR_URL_FROM_YOUR_EXISTING_REMOTE_ORIGIN
	pushurl = URL_TO_YOUR_FORK
```

`git push all`

## Digital Ocean Control Panel

* In app settings ensure run command is (as mentioned last class): 
    ```
    gunicorn --worker-tmp-dir /dev/shm locallibrary.wsgi
    ```



In your Digital Ocean App Platform Settings Environment variables
1. set them all from your .env file, but
    1. update the one for `DJANGO_ALLOWED_HOSTS` by appending
    ```
    ,${APP_DOMAIN}
    ```
    2. AFTER ADDING A DATABASE TO YOUR APP PLATOFRM APP
        1. update the `DJANGO_DATABASE_URL` one to be
    ```
    ${db.DATABASE_URL}
    ```
### Domain Setup

* Once deployed if viewing live app results in an error add this line to settings.py 'ALLOWED_HOSTS += ['lib.YOUR_DOMAIN.tech']'
* [Digital Ocean Tutorial **USE Option 2: Use a CNAME Alias**](https://docs.digitalocean.com/products/app-platform/how-to/manage-domains/#option-2)

 1. Go to your app page
 2. Click on `Networking` 
 3. Scroll down to `Add domain`
 4. Type in your domain ie (we want to use cname) `lib.yourdomain.tech`
 5. Click `You manage your domain`
 6. Copy the helpful link that digital ocean should give you ie `library-amx3l.ondigitalocean.app`
 7. Sign in to your `.tech` domain and set up a cname alias to point towards that helpful link
    - `lib.yourdomain.tech` should point to `library-amx3l.ondigitalocean.app`
 8. Don't forget to click `Add Domain` then give it time to process (Digital ocean says up to 72 hours I got about 5 minutes)
